## الخطوة 1 — ارفع الكود على GitHub (5 دقائق)

1. افتح **github.com** وسجّل دخول
2. اضغط **New repository** (الزر الأخضر)
3. اسم المستودع: `fairuz-flowers`
4. اضغط **Create repository**
5. في الصفحة الجديدة اضغط **uploading an existing file**
6. اسحب كل الملفات من المجلد واضغط **Commit changes**

---

## الخطوة 2 — ارفع على Render (5 دقائق)

1. افتح **render.com**
2. سجّل بنفس حساب GitHub
3. اضغط **New → Web Service**
4. اختر repository: `fairuz-flowers`
5. في **Environment Variables** أضف:
   - Key: `BOT_TOKEN`
   - Value: التوكن الجديد من BotFather
6. اضغط **Deploy**
7. انتظر دقيقتين حتى يكتمل

---

## الخطوة 3 — احصل على توكن جديد آمن

⚠️ **مهم:** التوكن القديم انكشف، لازم تجدد:
1. افتح **@BotFather** على تيليغرام
2. أرسل `/mybots`
3. اختر البوت
4. اضغط **API Token → Revoke current token**
5. انسخ التوكن الجديد واستخدمه في Render

---

## الخطوة 4 — فعّل البوت (ثانية واحدة)

بعد ما يكتمل الرفع، افتح في المتصفح:
```
https://اسم-تطبيقك.onrender.com/set_webhook
```
ستشوف: `{"ok": true}`
